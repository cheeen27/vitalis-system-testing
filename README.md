# Vitalis 健康饮食追踪系统测试项目

**[点击这里访问 Vitalis 测试网站](https://cheeen27.github.io/vitalis-system-testing/)**

## 1. 项目简介

Vitalis 是一个健康饮食与运动追踪 Web 应用，主要包含：

- 用户注册与登录
- 图片验证码
- 用户服务协议
- 饮食记录
- 运动记录
- 今日摄入/消耗/净卡路里统计
- 近 7 天趋势图
- 健康目标设置
- 周度健康报告
- 退出登录

项目原始页面为单 HTML 文件，数据主要在前端内存中处理。页面代码中可以看到登录、注册、饮食、运动、目标、看板和周报等功能实现。fileciteturn0file0L486-L610

## 2. 测试内容

本次测试采用**黑盒测试**方式，围绕功能验证、边界值/等价类、异常输入等场景设计测试用例。

- 测试用例：**200 条**
- P0：20 条
- P1：127 条
- P2：45 条
- P3：8 条
- 实际通过：**197 条**
- 实际失败：**3 条**
- 通过率：**98.5%**

完整测试用例位于 `test-cases/Vitalis_Test_Cases.xlsx`。

## 3. 测试结果

本轮执行发现 **3 个未通过用例**：

| 编号 | 模块 | 优先级 | 问题 |
|---|---|---|---|
| DIET-029 | 饮食 | P2 | 添加过去日期的饮食记录后，日期输入框没有恢复为当天日期 |
| EXER-029 | 运动 | P2 | 添加过去日期的运动记录后，日期输入框没有恢复为当天日期 |
| DASH-003 | 看板 | P2 | 趋势图 X 轴仅显示月-日，没有显示星期 |

## 7. 测试方式

本项目以手工测试为主，测试人员根据功能和输入规则设计测试用例，在浏览器中执行并记录实际结果；发现异常后提交至禅道进行缺陷管理。

> 本项目仅作个人演示用途，非生产级正式测试项目。
